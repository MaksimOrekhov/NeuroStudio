# NS-007 — Export selected collection to ZIP

Сценарий целиком: **Generate → Compare variations → Select Best → Download Collection.**

## Правила выбора итогового PNG сцены

1. Для сцены выбран Best → берётся он.
2. У сцены один вариант (старые коллекции NS-003/004/005 и режим «1 variation») → берётся он автоматически.
3. Вариантов несколько, Best не выбран → экспорт недоступен: «Select best images: 2/4».
4. Выбранный файл не готов или удалён с диска → ошибка с номером сцены (`scene 2: … missing on disk`). Другой вариант вместо него **не подставляется**.
5. Нужны все четыре сцены.

## Что в архиве

Ровно `scene-01.png`, `scene-02.png`, `scene-03.png`, `scene-04.png` — независимо от исходных имён `scene-NN-vNN.png`. Манифесты, `selections.json` и проигравшие варианты не включаются.

PNG кладутся **байт в байт** (метод «stored», без повторного сжатия и изменения разрешения; проверено побайтным сравнением SHA-256).

> **Метаданные:** исходные PNG ComfyUI содержат встроенные метаданные с полным промптом и графом генерации. Экспорт сохраняет их без изменений. Удаление метаданных — отдельная будущая функция.

## Backend

`GET /api/collections/:id/export` (`server/export.ts`): проверяет id, читает манифест и `selections.json`, выбирает четыре файла, проверяет, что каждый лежит внутри каталога коллекции (допустимы только имена `scene-NN[-vNN].png`) и существует, затем потоково отдаёт ZIP через `yazl` (одна небольшая зависимость; ничего не буферизуется в памяти и не пишется на диск). Ответы: 200 `application/zip` (`<id>-selected.zip`), 404 нет коллекции, 409 причина недоступности. Произвольные пути API не принимает. Экспорт не меняет файлы коллекции.

Статус готовности (`export: {ready, resolved, message}`) приходит в `/api/collections` и в ответе `PUT …/selection`, поэтому кнопка обновляется сразу после выбора.

## Frontend

В карточке коллекции кнопка **Download Selected (ZIP)**: активна при четырёх итоговых изображениях; иначе отключена и рядом причина («Select best images: 2/4»). Работает для старых коллекций с одним вариантом.

## Проверка

- `npm test`: 30 тестов без GPU/ComfyUI/Codex (5 новых в `tests/export.test.ts`): выбор Best по сценам и имена в архиве с побайтным совпадением, старая коллекция без `selections.json`, блокировка при незавершённом выборе, отсутствующий выбранный файл (в т.ч. без подмены), защита от выхода за каталог и чужой Host.
- Локальный сайт на копиях существующих PNG: кнопка отключена 0/4 → 1/4 → 2/4 → 3/4, после четвёртого выбора активна без перезагрузки; скачанные архивы (`legacy` и `var`) проходят `zipfile -t`, 4 файла, SHA-256 каждого совпадает с исходным PNG. Скриншот: `docs/screenshots/09-download-zip.jpg`.
- Генерация (Codex/ComfyUI) не затрагивалась.

## Ограничения

Экспорт одной коллекции за раз; ZIP не содержит манифест/prompt-plan; метаданные PNG не очищаются.
