# NS-005 — Multi-collection Autopilot

Одно нажатие **Generate Collections** создаёт 1–3 разные коллекции (по 4 кадра: 2 Crimson Oath + 2 Duskrose), 4 / 8 / 12 изображений. Выбор на главном экране, по умолчанию 3. Тема по-прежнему необязательна.

## Как устроено

- **Один вызов Codex на партию.** `generateBatch` (`src/codex.ts`) строит JSON-схему на лету из `schemas/prompt-plan.schema.json` (`{collections: PromptPlan[]}`, `minItems = maxItems = count`) и вызывает Codex один раз. Промпт требует существенно разные концепции внутри партии; история последних 20 коллекций передаётся как раньше. Таймаут = `CODEX_TIMEOUT_MS` (по умолчанию 300 с) × число коллекций. `generatePlan` из NS-003 остаётся для CLI.
- **Валидация до GPU.** `validateBatch` (`src/promptPlan.ts`) проверяет точное число планов, каждый существующим `validatePlan` и уникальность названий. Ошибка плана = запуск не доходит до ComfyUI.
- **Выполнение.** `AutopilotRunner` (`server/runner.ts`) сохраняет общий план в `output/batches/<id>/batch-plan.json` (планы, токены Codex, id коллекций, статус, ошибка) и последовательно вызывает существующий `runCollection` для каждой коллекции в её отдельной папке `output/collections/<id>/`.
- **Ошибка** останавливает партию: следующие коллекции не стартуют, принятые задания не отправляются повторно, готовые коллекции и все `prompt_id` остаются. Кадр, состояние которого неизвестно (таймаут или ComfyUI пропал после приёма задания), помечается «Unknown state» с `prompt_id`.
- **API:** `POST /api/autopilot/start {theme?, collections?}`; `collections` — целое 1–3 (без поля = 1, для обратной совместимости с NS-004; интерфейс отправляет выбранное значение, по умолчанию 3), иначе 400. `GET /api/status` дополнен `collection`, `collections`, `finished`; `done/total` считаются в изображениях всей партии.
- **UI:** переключатель 1/2/3, прогресс «Generating collection 2 / 3 — scene 3» и «6 / 12 images»; готовые коллекции появляются в галерее сразу после сохранения (манифест пишется после каждого кадра); при сбое видно, на какой коллекции остановились.

## Реальный прогон (2026-11-09, 2 коллекции из браузера)

- Один вызов Codex: 42,7 с, 21 009 токенов (19 071 вход, 1 938 выход). Концепции: «The Ember Kiln Cartographer» и «The Monsoon Courtyard Bellmaker».
- Коллекция 1 завершена: 4 PNG (2 Crimson Oath + 2 Duskrose), около 3,5 мин.
- Коллекция 2: первое задание принято (prompt_id сохранён), затем ComfyUI стал недоступен (его процесс на порту 8188 был перезапущен/закрыт на машине). Партия корректно остановилась: без повторов, без потери коллекции 1. Сквозной прогон двух полных коллекций **не завершён** из-за внешней причины; повторный запуск не выполнялся (лимит: один реальный прогон).

## Тесты

`npm test`: 19 без GPU (15 прежних + 4 новых): валидация количества (1–3, HTTP 400), один вызов Codex и 12 заданий для партии из 3, остановка партии при ошибке без повторов с сохранением `prompt_id`, `validateBatch`/`generateBatch` (точное число, уникальные названия, один процесс Codex).

## Ограничения

- Таймаут кадра прежний (20 мин). Состояние текущей партии хранится в памяти сервера; после перезапуска остаются манифесты (незавершённая коллекция показывается как Interrupted).
- Концепции внутри партии различаются по инструкции и проверке названий; смысловое сходство не проверяется.
