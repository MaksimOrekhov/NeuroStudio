# NS-002 — Autopilot Prompt Provider Feasibility

Дата: 2026-11-09. Ветка `ns-002-prompt-provider-poc` (база `75164e1`). Файл `NeuroStudio_PROJECT_CONTEXT_UPDATED.md` в репозитории отсутствует, использованы требования задачи.

## Итог

**Codex CLI работает без API-ключа на подписке ChatGPT и без ручного вмешательства: один запрос выдал валидный Prompt Plan.** Claude Code CLI на этой машине не авторизован, тест не пройден; кроме того, по условиям Anthropic для продукта/приложения, вызывающего Claude, нужен API-ключ. Для первого Autopilot рекомендуется **Codex CLI (`codex exec --output-schema`)**.

## Сравнение

| | Codex CLI | Claude Code CLI / Desktop |
|---|---|---|
| Способ запуска | `codex exec --output-schema schema.json -o out.json -` (промпт через stdin) | `claude -p ... --output-format json --json-schema ...`; Desktop только через MCP (Claude вызывает наши инструменты, а не наоборот) |
| Подписка | Да: «Sign in with ChatGPT», лимиты тарифа, API-ключ не нужен | Технически да (OAuth входа в CLI), но см. политику ниже; `--bare` подписку вообще не использует и требует `ANTHROPIC_API_KEY` |
| Вызов кнопкой NeuroStudio | Да: локальный backend запускает процесс | Только при ручном `claude login`; для автоматизации официально — API-ключ |
| API-ключ | Не нужен (но OpenAI рекомендует ключ для CI/серверных сценариев) | Нужен для «продуктов и сервисов на базе Claude» (Agent SDK и др.) |
| Ограничения | Нужна свежая версия CLI (модели привязаны к версии); внутри git-репозитория или `--skip-git-repo-check`; `auth.json` = пароль, хранить только локально; лимиты общие с остальным Codex/ChatGPT | Anthropic: OAuth подписки — «для обычного использования Claude Code и нативных приложений»; запрещено маршрутизировать запросы через подписку Pro/Max от лица пользователей и собирать/хранить токены. Лимиты Pro рассчитаны на индивидуальное обычное использование |
| Реальная проверка | **Успешно**: валидный план, ~47 с, ~21 тыс. токенов | **Не пройдена**: `claude auth status` → `loggedIn: false`; `claude -p` → «Not logged in». `/login` и токены не трогал |

### Что именно подтверждено про Codex

- Версия 0.133.0 отвечала от имени ChatGPT-аккаунта, но отклонила все актуальные модели («requires a newer version of Codex» / `gpt-6-luna` не поддерживается). После согласованного обновления до **0.167.0** (`npm i -g @openai/codex`, каталог `%APPDATA%\npm`, конфиг `~/.codex` не менялся) тот же запрос прошёл на модели из пользовательского конфига. Следствие: у Autopilot должна быть проверка версии/ошибки «model not supported» с понятным сообщением.
- Официальные варианты интеграции (по документации OpenAI): `codex exec` с кэшированным входом ChatGPT; API-ключ (`CODEX_API_KEY`, оплата по тарифу API); токены Codex для Enterprise; «Sign in with ChatGPT» для сторонних приложений (OAuth-партнёрство, сообщается как расширение от 2026-09-29, по вторичным источникам; для локального open-source-приложения условия участия не подтверждены).
- Для локального приложения, где пользователь сам вошёл в **собственный** Codex CLI, вызов `codex exec` — штатное использование CLI. Это не распространяется на размещение сервиса для других пользователей.

### Политика Anthropic (docs «Legal and compliance»)

Разработчики продуктов, использующие Agent SDK, должны применять API-ключ; нельзя предлагать вход через Claude.ai и маршрутизировать запросы через подписки пользователей; нельзя собирать/хранить OAuth-токены. Поэтому подписку Claude Pro для кнопки NeuroStudio использовать нельзя без отдельного разрешения Anthropic; обход через токены Claude Desktop не рассматривался.

## Prompt Plan

- Схема: `schemas/prompt-plan.schema.json` (концепция, ровно 4 кадра, `model ∈ {crimson-oath, duskrose}`, summary/positive/negative).
- Валидатор: `src/promptPlan.ts` (структура, 2+2 модели, уникальность промптов, запрещённые слова `brushing, camera, framing, twisted, parted lips, wide hips`). Схема не проверяет «21+» и «разные наряды/ракурсы» — это только в инструкции модели.
- Скрипт: `npm run plan:codex` → `output/prompt-plans/plan-<время>.json` + сводка в консоль. Модель можно задать `CODEX_MODEL=...` (иначе берётся из конфига Codex).
- Реальный образец ответа Codex: `docs/examples/prompt-plan.sample.json` («The Saltglass Conservatory»: четыре разных наряда, причёски, ракурсы и сцены у одной героини, 2 кадра Crimson Oath и 2 Duskrose). Валидатор его принял.
- Генерация изображений не запускалась.

## Рекомендация для первого Autopilot

**Codex CLI как локальный провайдер промптов** (`codex exec --output-schema`, запуск из backend NeuroStudio по кнопке):

1. Работает без API-ключа и без UI-автоматизации, возвращает данные строго по схеме.
2. Один запрос на коллекцию (около 20 тыс. токенов, ~1 мин): лимиты подписки расходуются умеренно.
3. Не нужен собственный OAuth: используется уже выполненный вход пользователя.
4. Claude остаётся запасным вариантом, но только через API-ключ (платно).

Риски и условия: пользователь должен быть залогинен в Codex (`codex login status`); версия CLI должна быть актуальной; приложение локальное, один пользователь — не выдавать доступ третьим лицам (не «мост» к подписке); лимиты ChatGPT общие, возможна ошибка лимита — нужен понятный отказ и повтор позже. Дополнительные API-расходы: нет. Следующий шаг (не в этой задаче): превратить скрипт в модуль backend, добавить генерацию N коллекций с контролем разнообразия между запусками.
