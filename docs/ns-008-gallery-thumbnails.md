# NS-008 — Gallery thumbnails

Галерея больше не загружает полноразмерные PNG (около 3 МБ каждый): карточки показывают WebP-превью, оригиналы открываются в Lightbox, скачиваются и попадают в ZIP как раньше.

## Как устроено

- **Превью:** `sharp` (одна зависимость, на нашей Windows установилась и работает), ширина до 512 px, пропорции сохранены, без увеличения маленьких изображений, WebP quality 78. Метаданные оригинала в превью не копируются.
- **Кеш:** файлы `output/thumbs/<collection>/<scene>.webp` (внутри `output/`, в Git не попадает). Превью создаётся при первом запросе, повторно используется, пока его mtime совпадает с mtime PNG; если PNG изменился — пересоздаётся. Параллельные одинаковые запросы разделяют одну конвертацию (`inflight`), запись атомарная (tmp + rename). Заранее для истории ничего не генерируется. Переменная `THUMBS_DIR` меняет каталог.
- **Endpoint:** `GET /api/collections/:id/thumbs/:file` с теми же проверками, что и `images/` (только `scene-NN[-vNN].png` внутри каталога коллекции, допустимый Host). Нет оригинала — 404. Если конвертация упала, отдаётся нетронутый оригинал с заголовком `x-thumbnail: fallback`.
- **Интерфейс:** `CollectionCard.vue` берёт `thumbs/` (lazy loading сохранён); Lightbox и «PNG ↓» по-прежнему `images/` (оригинал 1440×2176); ZIP-экспорт не менялся. Если файл коллекции удалён с диска, на его месте показывается «File missing», остальное работает.

## Измерения (локальный сайт, реальные коллекции)

- Превью 512×774: ~24–31 КБ против 2,9–3,4 МБ у PNG (в ~100 раз меньше); при открытии галереи 8 видимых превью = 242 КБ.
- Создание: ~60 мс на изображение; повторный запрос из кеша: ~2 мс.
- Lightbox открыл оригинал 1440×2176, а не превью. Скриншот: `docs/screenshots/10-gallery-thumbnails.jpg`.

## Тесты

`npm test`: 34 без GPU (4 новых в `tests/thumbs.test.ts`): формат/размер/пропорции, оригинал побайтно не меняется, маленькие не увеличиваются; повторное использование кеша, пересоздание при замене PNG, одна конвертация на параллельные запросы; защита путей и Host, доступность оригинала; fallback на оригинал при ошибке конвертации.

Совместимость проверена на реальных старых коллекциях (один вариант), частично неудачной коллекции без изображений и на коллекциях с вариантами (NS-006, тесты и ручная проверка).
