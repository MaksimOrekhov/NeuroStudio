# NS-004 — Web MVP: one-click Autopilot

Локальный сайт поверх конвейера NS-003: **Generate Collections** → Codex придумывает концепцию и 4 промпта → ComfyUI делает 4 PNG → галерея.

## Запуск (Windows)

1. Запустите ComfyUI (Desktop или `main.py`) на `127.0.0.1:8188`. Должен быть выполнен вход в Codex (`codex login status`).
2. В каталоге проекта:

```bash
npm install
npm start          # собирает фронтенд и поднимает http://127.0.0.1:8787
```

Откройте http://127.0.0.1:8787, при желании введите Theme и нажмите **Generate Collections**.

Разработка: `npm run dev:server` (API, порт 8787) и `npm run dev:web` (Vite, http://127.0.0.1:5173, проксирует `/api`). Переменные: `PORT`, `COMFY_URL`, а также `CODEX_MODEL`, `CODEX_TIMEOUT_MS`, `CODEX_BIN` из NS-003.

## API (Fastify, только `127.0.0.1`)

| Endpoint | Назначение |
|---|---|
| `GET /api/status` | `comfy` (доступность, версия, очередь) и `run` (`idle/planning/generating/completed/failed`, `done/total`, `currentFrame`, `error`) |
| `POST /api/autopilot/start` | `{theme?}` → 202; 409 если запуск уже идёт; 503 если ComfyUI недоступен (Codex в этом случае не вызывается) |
| `GET /api/collections` | последние коллекции (из `output/collections/*/collection.json`) |
| `GET /api/collections/:id` | одна коллекция |
| `GET /api/collections/:id/images/scene-NN.png` | PNG (`?download=1` — как вложение) |

Запуск идёт в фоне, фронтенд опрашивает `/api/status` (1,5 с во время работы, 5 с в покое). Состояние запуска хранится в памяти, история — в JSON-манифестах NS-003.

## Поведение и защита

- Один запуск одновременно: блокировка ставится синхронно, параллельные `start` получают 409.
- Перезапуск сервера ничего не запускает сам. Манифест со статусом `running`, который никто не выполняет, показывается как **Interrupted** (не Completed), с `prompt_id` неопределённых кадров; повторно кадры не отправляются.
- Ошибка Codex/ComfyUI останавливает запуск, повторов нет; новый запуск — только по кнопке.
- Защита от DNS rebinding (проверка `Host`) и кросс-сайтовых POST (проверка `Origin`); PNG отдаются только как `scene-NN.png` внутри каталога коллекции.
- Если ComfyUI недоступен, кнопка отключена с пояснением.

## Разнообразие концепций

Перед запросом в Codex передаются названия последних 20 коллекций с инструкцией предложить существенно иную концепцию (`avoid` в `src/codex.ts`). В реальном прогоне после «The Saltglass Conservatory» получена «The Last Signal at Bluehour».

## Тесты

`npm test` — 15 тестов без GPU (10 из NS-003 без изменений + 5 серверных): запрет второго запуска, 503 при недоступном ComfyUI, ошибка Codex без повторов, безопасная выдача PNG и блокировка чужих Host/Origin, история концепций. `npm run typecheck` — `tsc` и `vue-tsc`.

## Ограничения

- Миниатюры — полноразмерные PNG (около 3 МБ), загружаются лениво; галерея показывает 8 последних коллекций. Сжатие превью не делалось.
- Состояние текущего запуска живёт в памяти: после перезапуска сервера индикатор прогресса пропадает, остаётся манифест.
- Одна коллекция за нажатие, без очереди нескольких коллекций.
- Таймаут кадра 20 минут (ожидание очереди ComfyUI при ручных генерациях пользователя).
