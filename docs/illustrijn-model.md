# IllustrijN — третья модель изображений

Добавлена локальная модель `IllustrijN.safetensors` из `models/diffusion_models/` ComfyUI, id в API/планах: `illustrijn`.

Проверка файла показала `model_family=anima`, `model_type=anima`, BF16. Все 685 diffusion tensor keys и их размеры совпадают с diffusion-частью Crimson Oath и Duskrose. Работающий ComfyUI 0.45.2 предоставляет файл в опциях UNETLoader.

Модель использует существующий `workflows/anima-crimson-oath.api.json`: заменяется только UNET. Text encoder, VAE, negative prompt, sampler и параметры обычной генерации остаются прежними. Установка новых нод/моделей и обновление ComfyUI не требуются.

В интерфейсе доступны:

- «Только IllustrijN» — все кадры этой моделью;
- «Для каждого кадра» — IllustrijN вместе с другими моделями;
- «Автоподбор» — прежнее правило распределения по порядку каталога теперь использует три модели: 1 кадр — Crimson; 2 — Crimson/Duskrose; 3 — Crimson/Duskrose/IllustrijN; 4 — Crimson/Crimson/Duskrose/IllustrijN.

Сохранённые коллекции сохраняют своё распределение моделей. Старый формат планов с 2 Crimson + 2 Duskrose по-прежнему проверяется прежними правилами; новые планы получают модели из запроса. Обновлён enum текущей JSON-схемы; поля и формат планов не менялись. Перегенерация IllustrijN использует собственный сохранённый граф без нового вызова Codex.
