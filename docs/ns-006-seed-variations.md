# NS-006 — Seed variations and best-image selection

## Что добавлено

- **Seed variations: 1 / 2 / 4** на главном экране (по умолчанию 2) рядом с выбором 1–3 коллекций. Итог показывается до запуска: `3 collections × 4 scenes × 2 variations = 24 images`.
- **API:** `POST /api/autopilot/start {theme?, collections?, variations?}`; `variations` ∈ {1, 2, 4}, иначе 400. Без поля = 1, поэтому прежние клиенты и CLI работают как раньше (интерфейс отправляет выбранное значение). CLI: `npm run autopilot -- --variations 2`.
- **Один вызов Codex на партию** без изменений: варианты не создают новых промптов. Для каждой сцены используются тот же positive, negative, модель и настройки workflow; меняется только seed (все seed в партии уникальны).
- **Файлы:** при `variations = 1` прежние имена `scene-NN.png/json`; при 2 и 4 — `scene-NN-vNN.png/json` (+ seed, модель, полный граф, `prompt_id`, статус, history). Манифест получил `variations` и `variant` у каждой записи.
- **Прогресс** считается во всех изображениях (`8 / 24 images`). Очередь та же последовательная (`runCollection`), группировка по модели, при ошибке один неудачный вариант останавливает запуск без повторной отправки; готовые изображения и `prompt_id` сохраняются, неопределённый статус остаётся «Unknown state».
- **Галерея:** внутри коллекции остаются 4 сцены; под каждой — переключатель вариантов `v1 v2 …`, кнопка **Select Best**, отметка «★ Best», крупный просмотр и скачивание. Показывается выбранный вариант, иначе текущий просматриваемый. Ровно один лучший на сцену (повторный выбор заменяет, нажатие на выбранный снимает выбор).
- **Выбор хранится в `selections.json`** внутри папки коллекции (`{"2": 1, "3": 2}`), переживает перезапуск; PNG не меняются и не удаляются. `PUT /api/collections/:id/selection {frame, variant|null}` (можно выбрать только готовое изображение).
- **Совместимость:** коллекции без поля `variant`/`variations` (NS-003/004/005, `scene-01.png`) открываются как вариант 1 без миграции, выбор лучшего в них тоже работает.

## Проверка

- `npm test`: 25 тестов без GPU (из них 5 новых/расширенных для NS-006): 4×v заданий для v = 1, 2, 4; уникальность seed; одинаковые промпты и граф при смене seed (кроме seed и имени файла); сохранение выбора и ответы 400/404; историческая коллекция; остановка без повторной отправки при ошибке варианта; 24 задания и один вызов Codex для 3×4×2 (моки).
- Интерфейс проверен на копиях существующих PNG во временной папке (`COLLECTIONS_DIR`): коллекция 4 сцены × 2 варианта с одним неготовым, коллекция старого формата, выбор лучшего, перезапуск сервера (выбор сохранился). Скриншоты: `docs/screenshots/07-variations-selector.jpg`, `08-grouped-select-best.jpg`.
- **Реальный GPU-прогон не выполнялся** (по условию задачи: пока не подтверждена стабильность ComfyUI после NS-005A). Реальный сценарий «1 коллекция × 2 seed-варианта» ещё не проверен.

## Ограничения

- Переключение варианта и выбор не имеют ZIP-экспорта: скачиваются отдельные PNG.
- Миниатюры — полноразмерные PNG (как раньше), галерея показывает 8 последних коллекций.
